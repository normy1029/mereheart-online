# Mereheart Online — โหมดออนไลน์

ไฟล์ในโฟลเดอร์นี้
- `index.html`  ตัวเกม (เซิร์ฟเวอร์เสิร์ฟให้ที่ `/`)
- `server.js`   เซิร์ฟเวอร์ WebSocket (ไม่ต้องติดตั้งแพ็กเกจอะไรเพิ่ม ใช้ Node 18 ขึ้นไป)
- `package.json`

## ลองบนเครื่องตัวเอง
```
node server.js
```
เปิด http://localhost:3000 สองแท็บ (หรือสองเครื่องในเครือข่ายเดียวกันที่ http://IP-เครื่อง:3000) สร้างตัวละครแล้วจะเห็นกันและกัน มีป้าย ONLINE ที่ด้านบนจอ

## เอาขึ้นอินเทอร์เน็ต (แนะนำ Render.com ฟรี)
1. สร้างที่เก็บโค้ดบน GitHub แล้วอัปโหลดทั้ง 3 ไฟล์
2. Render.com → New → Web Service → เลือก repo
3. Runtime: Node, Build Command: เว้นว่าง, Start Command: `node server.js`
4. กด Deploy แล้วจะได้ลิงก์ https://ชื่อ.onrender.com ส่งให้เพื่อนเล่นได้เลย
(Railway, Fly.io, VPS ใช้วิธีเดียวกัน: รัน `node server.js` แล้วเปิดพอร์ตตาม PORT)

แผนฟรีของ Render จะหลับเมื่อไม่มีคนเข้า ครั้งแรกอาจรอเปิดสักครู่

## ตัวเลือก
- `PORT` พอร์ต (ค่าเริ่มต้น 3000)
- `MAX_PLAYERS` จำนวนผู้เล่นสูงสุด (ค่าเริ่มต้น 100)
- `ALLOWED_ORIGIN` จำกัดให้เชื่อมต่อได้เฉพาะจากเว็บนี้ เช่น `https://ชื่อ.onrender.com`
- ถ้าโฮสต์ไฟล์เกมแยกจากเซิร์ฟเวอร์ เปิดเกมด้วย `?server=ชื่อ.onrender.com` (หรือ `?server=wss://โดเมน/ws`)
- ถ้าเชื่อมต่อไม่ได้ เกมจะเล่นแบบออฟไลน์ตามเดิม (บอตตัวอย่าง)

## ตอนนี้ซิงก์อะไรบ้าง
เห็นผู้เล่นคนอื่นเดินและท่าทาง, แชท (ฟองข้อความ), เอฟเฟกต์สกิลของกันและกัน, ชื่อและหน้าตาตัวละคร
## ยังไม่ซิงก์ (ขั้นต่อไป)
มอนสเตอร์, ไอเทมตก, ดาเมจ และการเซฟตัวละคร (ยังเก็บในเบราว์เซอร์ของแต่ละคน) ผู้เล่นแต่ละคนยังเห็นมอนสเตอร์ของตัวเองแยกกัน
